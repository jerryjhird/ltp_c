# Lean Transfer Protocol Library
### single header library for interacting with LTP packets

LTP or Lean Transfer Protocol is a protocol made by me (jerryjhird) as a modular alternative to http

## Example:
```c
#define LIBLTP_IMPLEMENTATION
#include "libltp.h"
...

```
(only use `#define LIBLTP_IMPLEMENTATION` in one .c file)
